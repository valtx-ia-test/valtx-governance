## Contexto

La aplicación permitirá a los usuarios generar mockups en HTML a partir de descripciones en lenguaje natural. Esto facilitará la creación de prototipos y la visualización de ideas de diseño sin necesidad de conocimientos técnicos en programación.

## Requisitos (EARS)

| ID          | Descripción                                                                                      |
|-------------|--------------------------------------------------------------------------------------------------|
| REQ-MOCK-001| WHEN a user provides a natural language description, THE SYSTEM SHALL generate a corresponding HTML mockup in real-time, complying with POL-PE-CONSENT-001, Article 1. |
| REQ-MOCK-002| WHEN the user requests to save the generated mockup, THE SYSTEM SHALL allow the user to download the HTML file, complying with POL-PE-REGISTRO-008, Article 2. |
| REQ-MOCK-003| WHEN the user wants to share the mockup, THE SYSTEM SHALL provide a shareable link, complying with POL-PE-SEG-006, Article 3. |
